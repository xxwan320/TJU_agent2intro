## 本地使用的模型

文本和工具规划使用 GLM-5.1，通过后端配置的 OpenAI 兼容网关访问；GLM 权重不存放在本项目内。

三维重建相关模型按输入类型和本机安装情况使用：

- 多视角融合：DA3-SMALL 估计相机与深度，之后用 CPU TSDF 融合观测表面。
- 单图重建：TripoSR 为现有默认提供器；Hunyuan3D-2mini、2mini-turbo 和完整 Hunyuan3D-2 是可选提供器。
- 文字概念建模：Shap-E，配合 CLIP 文本模型；结果属于概念模型，不代表实景测绘。
- 图像恢复辅助：SmolVLM 在恢复流程需要时描述图像内容。
- 前景提取：rembg 使用 U2-Net 或 U2-NetP 权重。

这些模型是否可用取决于对应的本地安装和权重。上述模型清单用于说明项目的本地模型链路，不表示每个运行环境都已安装全部权重。
