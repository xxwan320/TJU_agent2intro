# 本地使用与测试指南

## 1. 先打开应用

当前主目录 E:\AI4TJU 的构建版本运行在 **http://127.0.0.1:8000**。用 Chrome 或 Edge 打开，不必启动桌宠程序，也不需要再次输入已经配置的模型密钥。

正常情况下应看到珂莱塔人物舞台、校区/建筑卡片、对话区域和运行日志入口。M1 浏览器工具因无法可靠确定当前 URL 而停止，本文件是给你的现场检查步骤；尚无合并版本截图证明画面与播放通过。

若当前地址打不开：

```powershell
cd E:\AI4TJU
.\scripts\start-app.ps1
```

已运行时脚本会提示，不会重复启动。停止或重启：

```powershell
.\scripts\stop.ps1
.\scripts\start-app.ps1 -Build
```

停止脚本仅处理本项目记录的 PID，并比对创建时间。端口占用时不会杀其他程序。需要换端口可用 ` .\scripts\start-app.ps1 -Port 8080 `，对应访问 http://127.0.0.1:8080。

## 2. 五分钟试用流程

|步骤|怎么操作|应检查的结果|
|---|---|---|
|人物|打开页面，观察舞台约 5 秒|用户指定的 kelaita/珂莱塔 Live2D 出现；保留原水印。不是 3D，嘴形不承诺同步。|
|角色与聊天|选择“普通聊天”，输入“你好，请用一句话介绍你的名字和职责。”|真实模型回复，名字为珂莱塔，职责是校园导游。回复下显示 glm-5.1、耗时和供应商用量或未提供。|
|追问|第一问加“请记住代号蓝宝石”，第二问“刚才的代号是什么？”|同一会话能复述。清空后新会话不应继承该代号。|
|校园资料|选择“北洋园校区”，在“郑东图书馆”卡片点击“介绍这里”|回答关联所选建筑，展开来源能看到官方标题、片段和链接。|
|场景动作|在该点位下输入“请介绍这里并显示建筑卡片。”|资料卡实际显示后，日志才记录 scene completed；当前只有 2D 卡片，没有 3D 漫游。|
|请求日志|发送问题后立即打开右上“运行日志”|回答未结束时先出现后端 started，之后才出现 completed 或 failed。浏览器 avatar/speech 事件与后端分开。|

普通聊天不依赖校园检索；校园问答只能依检索到的资料回答。当前只收录少量资料，卫津路校区暂无已核实建筑卡片是正常空状态。

## 3. 语音体验

先完成一轮短回答，点击回答下“播放”。浏览器可能要求由你点击触发播放。也可在发送前勾选“自动播报”。第一次语音查询或合成依赖网络，需要稍等。

现场检查：
- 听到中文播报时，人物状态才应为 speaking。
- 播放完毕应回到 idle。
- 播放中点击“停止”，应立即停止；几秒后不应恢复旧音频。
- “自动播报”关闭时，文字回答不应自行播放。
- 超过 4000 字的回答不会偷偷截断播报，会提示分段提问。

已实测的是服务端 Edge TTS 音色查询、音频合成/取回及取消；你本机扬声器是否出声、浏览器权限、人物状态联动尚需现场确认。当前使用普通中文音色，**不是珂莱塔克隆音色**；时间戳能力为 none，不是准确中文口型。

**麦克风输入暂未完成**：未配置独立 ASR 服务，点击语音输入应明确提示不可用。不要将 GLM 聊天 URL 填到 ASR 中，也不要把“有麦克风按钮”当成已接通识别。后续配置独立 CAMPUS_ASR_URL/MODEL/API_KEY 后重启服务，再由你授予浏览器麦克风权限并测试中文识别。

## 4. 取消、清空、重试与输入法

1. “内容生成”模式请求一篇较长的虚构参观感想，生成中点“停止”。应显示取消，旧回复不应随后覆盖页面；上游停止可能显示未确认，这是实际状态。
2. 使用“使用新请求重试”，检查产生新一次请求；取消/失败轮次不应加入模型历史。
3. 回答生成或音频播放中点击清空会话，应清空消息/日志，并停止旧操作；随后发新问题，不应出现旧消息或旧音频。
4. 使用中文输入法输入“珂莱塔带我看看校园”：候选词确认时按 Enter 不应误发送。确认文字后再按 Enter 发送，Shift+Enter 换行。
5. 将窗口缩到约 390–430 像素宽，检查页面可滚动、发送/停止按钮可点、来源和日志可读。不要把仅有响应式 CSS 当成小屏实测通过。

若浏览器发生错误，请记录使用的浏览器版本、步骤、界面错误码及截图。可从“运行日志→脱敏导出”导出事件；不要附 .env、原始录音或含其他个人信息的浏览器窗口。

## 6. 常见问题

|现象|处理|
|---|---|
|PowerShell 提示脚本被禁用|本次进程可使用 powershell -NoProfile -ExecutionPolicy Bypass -File E:\AI4TJU\scripts\start-app.ps1；不修改全局策略。|
|8000 已占用|若是本项目，先运行 stop.ps1；若是其他程序，用 -Port 8080。|
|模型未配置|只在本机运行 scripts/Configure-Local.ps1 隐藏输入，随后重启。已有配置无需重填。|
|模型超时/认证失败|查看页面安全错误码；先确认网络及网关授权。不会自动换模型。不要把密钥发到聊天或截图。|
|人物加载失败|确认 public 下 kelaita/Core 资源存在；使用 Chrome/Edge 的正常图形环境。图形设置、浏览器权限由你自己检查。|
|没有中文音色/播放失败|确认网络、设备音量和浏览器播放状态。可关闭自动播报，点击当前回答下的播放重试；专业中文语音仍属后续。|
|资料为空|当前 7 条摘要/2 个北洋园点位，不代表覆盖全部天大；没有来源时应说明资料不足。|
|新机器 clone 后没人物|GitHub 只含源码与许可记录；将有权使用的素材归档准备到项目 .runtime/asset-source，或 setup -AssetSource 指定该归档。不得把人物授权当作代码 MIT。|

新环境需要 Node >=22.12、Python 3.11、Git。安装使用固定锁文件：
` .\scripts\setup.ps1 -Python '你的Python311路径' -AssetSource '素材归档目录' `。
归档应包含 kelaita/ReadMe.txt、kelaita/runtime 下模型相关文件和 live2dcubismcore.min.js。项目 `.env` 仅保存在本机，不纳入 Git。
