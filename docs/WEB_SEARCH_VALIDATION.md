## 本机验证步骤

1. 打开或刷新首页；在线地图应自动加载。
2. 在内容生成中输入校史馆介绍，生成讲解词；展开参考资料和运行日志观察联网结果。
3. 点击“IP 城市定位”或“持续 IP 定位”。持续更新间隔30秒，可随时停止；切校区后停止。IP表示出口网络所属粗略区域。
4. 开启语音，切换四个选项并实际播放。若浏览器拦截自动播放，点击“恢复声音”。
5. 选中校史博物馆，点击“在在线地图查看”，确认高德候选地点；也可从回答底部“在地图查看”进入。点击“在地图选择起点”，在地图选点后规划步行路线，使用“上一步／下一步”或点击步骤查看路线高亮。
6. 查看新生成答案：正文没有来源ID，参考资料集中在底部；自动朗读、读全文和读这一段不应念来源ID或链接。
7. 强制刷新页面后，无需先定位或手动选点，选中目的地，点击“从 IP 位置步行到这里”。观察自动定位、目的地匹配和路线；有同名候选时选择后自动继续。检查路线顶部的IP区域中心说明。
