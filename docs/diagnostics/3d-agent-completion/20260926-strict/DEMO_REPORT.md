## 1. 模型调用深度

融合链路：真实照片 → 局部特征重叠检查 → DA3-SMALL 联合预测两相机、内参、深度与置信度 → 独立特征重投影检查 → 置信加权 TSDF → 有观测边界的 marching cubes 网格 → GLB → 浏览器查看/下载。

文字链路：真实 GLM 工具循环（4 次模型响应、4 次业务工具）→ 1 次 GLM 英文条件整理 → Shap-E text300M 扩散与解码 → GLB 检查、导出。调用日志见 text-demo/live.json。没有把固定工具脚本或预生成展示冒充本次模型调用。

## 4. 创新点与边界

工程贡献是将可解释输入检查、联合相机深度模型、独立重投影、真正的体素融合、观测范围声明和 Agent 实际工具记录连成可复查的闭环；不是新训练的基础模型，也不把开源模型自身成果称为本项目算法创新。

没有按建筑名称手工拼几何，没有用公开建筑尺寸制造重建成功。置信度低的天空被过滤；未拍到的背面没有补造。输入缺少对应结构、重复幕墙、反光、水面和视角跨度仍可能失败。当前生产多图入口仅声明已验证的 2 图容量，不承诺任意图片成功。文字生成是概念外观，门窗细节不精确，不代表真实建筑。
