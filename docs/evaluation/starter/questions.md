# AI4TJU 标准问题与页面验收

本文件就是本轮问题集。建议项目路径：`E:\AI4TJU\docs\evaluation\starter\questions.md`。已有40条扩展集在同目录 `cases.jsonl`。本文件提供验收预期，不是程序已经回答正确的记录；下面所有项目初始状态均为 **NOT_RUN**。

采用固定校区“北洋园”，优先使用原有大通学生中心、郑东图书馆照片，增加截图暴露问题的尚贤石。不补图、不重新识别图片。跨校区测试单独说明。

## 一、基础问答（12题）

| ID | 输入与上下文 | 标准答案/应有行为 | 不应出现 |
|---|---|---|---|
| Q01 | 北洋园校区何时投入使用？ | 2015年9月；沿用本地支持来源。这个日期来自用户探针，运行前核对原文。 | 稳定本地命中后仍固定等联网；无依据添加具体日号 |
| Q02 | 郑东图书馆在哪个校区？ | 天津大学北洋园校区；命中对应POI。依据为用户探针，运行时核对本地记录。 | 说成卫津路；顺便编造今天关门时间 |
| Q03 | 当前选中尚贤石：“请介绍一下这里。” | 说明北洋园的尚贤石，采用下方已查官网事实；回答与当前poiId一致。 | 只说目录里有这个地点；回答大通/另一地点 |
| Q04 | “尚贤石上的字是谁写的？” | 赵冷月题写，“尚贤”取自《墨子·尚贤篇》。 | 把书写者、捐赠者混为一人 |
| Q05 | “郑东图书馆今天几点关门？” | 查询有关官方开放信息；查不到当日适用依据时明确未确认，并提供实际查到的官方入口。 | 用历史开放公告直接保证今天时间；伪造查询成功 |
| Q06 | “北洋园启用年份，以及图书馆今天几点关门？” | 先给2015年的稳定事实，再分别处理动态开放信息。 | 整个问题只答年份；为了快而省略动态部分 |
| Q07 | “北洋园XX未来科技展厅今天票价多少？”（不存在于库的测试名称） | 说明未找到可靠对应地点，请求名称或官方链接。 | 编造票价、坐标；不相关来源支撑结论 |
| Q08 | 北洋园；必去选“郑东图书馆”，避开参观点选“大通学生中心”，地图已有起点；“安排一个30分钟的游览。” | 包含必去ID，不安排避开点停留；实际路线与地图同步；总耗时完整可得时再判断30分钟可行。 | 忽略必去；总步行未知却保证30分钟；保证路线一定绕开大通区域 |
| Q09 | 同一地点同时加入必去与避开 | 选择阶段阻止冲突或明确要求用户解除冲突，不开始付费规划。 | 静默删除一个约束；模型随便决定 |
| Q10 | “出发前有什么建议和最近学校信息？” | 有简短行程建议；查询有关官方信息；来源带日期。可提9月7日发布的网上校史馆上线消息，明确是近期消息。 | 将旧消息说成今日发布；满屏重复“待核验”；无依据保证可入校 |
| Q11 | “今天学校有没有临时闭馆通知？”；模拟官网超时 | 说明本次未能完成核验；保留已有资料并标明时间。 | 把超时说成没有通知/正常开放 |
| Q12 | 说普通话：“我想去郑东图书馆，请帮我规划路线。” | 真实ASR产出可编辑文本；用户确认发送后解析目标ID，使用已确认起点进入原有路线流程。 | 用TTS代替ASR；只展示波形；未确认就执行；把不相似地点强行匹配 |

“标准答案”用于事实与行为判定，不要求逐字复述。Q05/Q06/Q10/Q11为动态题，不提前写死当日开放/闭馆答案。Q12要区分音频夹具与真实麦克风；纯模拟识别不能算ASR通过。

## 二、可直接使用的讲解样例

选中尚贤石时可显示并朗读：

> 你现在看到的是尚贤石，它于2015年落户天津大学北洋园校区。石上的“尚贤”二字由书法家赵冷月题写，取自《墨子·尚贤篇》。这块石头也被称作“泰山孔子石”。参观时，可以留意石上的题字。

依据：[天津大学新闻网：泰山孔子石落户北洋园，2015-09-28](https://news.tju.edu.cn/info/1003/89019.htm)。末句是导览建议，不是官方参观规定。定位只能沿用地图实际匹配结果，不能从文章自行推算坐标。

近期信息样例：

> 想在出发前了解校史，可以先查看网上校史馆。天津大学档案馆近期发布了其上线消息，支持线上浏览展陈。该消息列于2026年9月7日公告，不是9月17日当天新闻，也不代表实体馆当天开放。

依据：[档案馆公告](https://dag.tju.edu.cn/web/news/info/231147/237592.htmlx)，[公告日期所在首页](https://dag.tju.edu.cn/)。

## 三、用户实际操作验收（8组）

| ID | 操作 | 必须看到的结果 | 证据 |
|---|---|---|---|
| U01 | 大通→郑东→大通，快速点击 | 图、标题、介绍、地图选中一致；旧请求不能覆盖；图片真正加载成功 | 真实DOM截图、图片naturalWidth、当前poiId/marker |
| U02 | 选尚贤石→开始讲解→停止 | 有可读介绍；缺图有当前点提示；真正开始播放，停止后不复活 | TTS与audio.play结果、playing/currentTime、人工听音分别记 |
| U03 | 大通讲解中选郑东，再点开始 | 大通声音和队列停止；郑东介绍与声音一致；嘴形对应实际播放 | 播放事件及角色观察；模拟状态不能代替 |
| U04 | 关闭语音或浏览器阻止播放时点开始 | 就地出现明确启用/再次播放入口；没有“正在播放”的假状态 | 真实错误提示及恢复步骤 |
| U05 | 用选项设置必去、避开，再制造冲突及换校区 | 传ID；冲突不提交；校区切换处理旧选项；避开含义明确 | 提交参数、控件状态，秘密字段不记录 |
| U06 | 地图选起点，选择两站行程并规划 | 当前地图自动绘制真实分段路线；列表/地图点可互选；普通选点保留线，清空移除线 | 真实地图截图、routeId与路线结果；不只HTTP200 |
| U07 | 生成出发提示，再模拟官网成功/超时/过期通知 | 有建议和实际来源；日期正确；重复风险句消除；不同查询状态不混淆 | 前端截图＋来源链接＋工具trace；夹具明确标记 |
| U08 | 授权麦克风、说Q12、停止、编辑、发送；另测拒绝和取消 | 真实识别出文字并可编辑；释放麦克风；拒绝可恢复；取消结果不覆盖新输入 | 录音格式、真实ASR结果、DOM；麦克风实测与WAV夹具分开 |

## 四、如何记录结果

每项记录：`id、build_id、campus_id、selected_poi_id、输入/操作、期望、实际结果、状态、证据类型、证据路径、耗时、外部调用数`。

状态使用 PASS / FAIL / BLOCKED / NOT_RUN。证据类型使用 browser、human_audio、live_http、recorded_replay、mock，不能以mock的PASS覆盖browser的BLOCKED。

RAG额外记录：命中本地document/fact/source IDs、是否进入生成上下文、是否调用官网及理由。Agent额外记录：真实tool_call（如果支持）、工具参数校验、实际来源、调用次数、超时/降级状态。

性能采用相同两张照片、相同问题和缓存条件，分别测介绍出现、首音、行程首次展示、地图画线、ASR结束到文字。3次样本报告原始值与中位数即可，不能据此推断P95或稳定加速倍数。记录失败样本，不从平均数中隐藏。

优先做U01—U08；Q01—Q12挑选覆盖已改分支的真实调用，其余用已录制结果。不要为了跑满表而重复消耗模型和地图预算。通过后在项目开发说明留下本文件入口。


## 五、新增检索与响应验收（R01—R08）

这些项目仍为NOT_RUN。时间数值是配置检查或试验目标，不是本包测出的收益。优先用真实来源小样本建立录制，其余失败、乱序与超时用标明来源的夹具复验。

| ID | 输入/场景 | 通过要求 |
|---|---|---|
| R01 | 尚贤石本地仅有目录句，校友网页只有标题/图片 | 判定正文不足，查相关新闻网正文，生成有来源介绍；缓存后再次开始讲解不查网页、不调用GLM。图片映射不改变。 |
| R02 | 文化问题本地/官网不足，北洋维基有相关资料 | 备用层按政策命中并标社区来源；同校区同地点；不能将社区说法自动写成核验完成的官方事实。 |
| R03 | “今天能进图书馆吗？”仅有社区旧帖，图书馆正文不可解析 | 不给确定开放结论；unavailable/partial与no_evidence正确区分；提供官方入口，未解析空页不作为无公告证据。 |
| R04 | 旧官方公告、另校区新通知、同文多次转载一起返回 | 按实际适用地点/日期筛选；不以先返回、最新日期或多数票直接决定。检查否定词及有效期未被上下文裁剪。 |
| R05 | 主源慢、备用源慢，或用户中途取消 | 联网阶段3500ms共享截止且受总请求截止约束；轮间不调用模型；到期不启动新搜索，不逐个累加超时；供应商计费不可见部分如实标注。 |
| R06 | 同问句切校区、换poi、改变必去/避开、跨日；动态缓存到期 | 缓存隔离正确；真实路线顺序不被集合排序打乱；过期规则不当今日已核验；失败冷却不成为“没有公告”。 |
| R07 | 两个消费者同时同查询；取消一个；快速A→B→A | 只发合并后的实际请求；仍有订阅者时不中断共享任务；迟到结果不覆盖当前模块；普通选点不取消路线通道。 |
| R08 | 同样本冷/热缓存测量；先发“正在查询”，后出正文 | 状态/占位不算有效首正文；分别记录正文可见、完成、首音、地图画线和请求数；功能与事实质量不退化；本地300ms目标未达如实记录。 |

补充起点按钮回归：定位一次、持续定位、IP城市定位、持续IP定位、地图选起点、坐标输入、实时跟随逐项记录启停及反馈。拒绝GPS不应阻塞地图选点；IP粗定位不得自动替代校园精确步行起点。

性能记录模板在 `performance_results.template.json`。全为null/NOT_RUN；本地执行者填同构建下改前与改后的原始值。服务端和浏览器时钟各自测量，不直接相减不同设备的时间戳。受模型网关影响的未达标项保留，不用更快的静态问题替换原来的复杂问题后宣称整体提速。
