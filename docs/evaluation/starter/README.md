# AI4TJU 完整修复与轻量Agent执行包

2026-09-17合并版。唯一任务入口是 `local_task_prompts.md`，已合并讲解、图片加载、地图联动、选项式行程、普通话ASR、分级查询与响应提速。

**本包是执行提示词＋来源/策略配置＋问题集，不含E:\AI4TJU源码，也没有将这些功能部署进你的应用。** 已实际完成的是基础网页查阅、模板合并及文件一致性校验；应用运行和加速结果仍待本地执行。

## 使用

1. 将ZIP内文件解压至 `E:\AI4TJU\docs\evaluation\starter\`，保留该目录已有用户修改。
2. 在项目根目录的本地Codex中，要求它完整读取该目录的 `local_task_prompts.md`，按文内顺序修改代码并验收。
3. 来源与策略配置按项目现有schema接入，不能只复制文件就宣布Agent完成。若原项目已有LangGraph，复用；否则使用现有FastAPI内的轻量工具工作流。
4. 结果应写入项目 `docs/interaction/<本轮时间>/`，分别报告代码完成、供应商可用、真实页面验证和速度实测。

## 本轮框架选择

一个查询服务处理本地RAG、官方查询和有条件的社区补充。默认程序分流后只调用一次模型；确需工具选择且网关支持时，最多两次。选点和资料充分的固定讲解不调用模型、不联网。来源多不等于证据独立；今日入校/开闭馆需要适用官方依据。

检索阶段预算3.5秒，两轮共用并受整个请求截止限制。45秒整体截止是资源边界，不是速度目标。已有内容先显示，状态提示不算有效首正文；真实步行未完成的行程仍标草稿/待路线，不能为了快而宣称可以出发。

## 核查发现

校友网尚贤石页面可提取正文不足，新闻网有历史介绍；北洋维基景点目录可作社区补充。图书馆官网身份与跳转已确认，但本轮未读到正文，默认不启用未验证抓取器。所有网址仍须验证在本地环境的可用性，网页读取成功不证明整条检索链可用或当日可入校。

依照用户报告，原有LocalKnowledge资料被加入GLM上下文，属于基础RAG；此处未重新检查仓库源码。TTS产出MP3、HTTP200、hook/SDK夹具通过都不代替真实播放、地图DOM或麦克风验收。
