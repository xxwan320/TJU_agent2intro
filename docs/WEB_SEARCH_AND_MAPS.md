# 联网问答、地图与语音

校园问答和内容生成会自动搜索公开网页；普通聊天在请求查询、最新信息或事实说明时启动检索。后端使用 DDGS，优先排列教育机构和政府来源，最多读取三页正文。只把当前主题提交给搜索服务，不附带完整会话或设备坐标。搜索服务限时12秒、缓存10分钟，失败时继续由原 GLM 提供基本解释或创作草稿，明确尚未核实的信息。

引用格式问题不再导致整段答案失败。正文清除来源ID标记，参考资料统一在回答末尾展示；缺失引用或无法对应的引用附末尾资料提示。流式正文也隐藏未收完的来源标记；自动朗读、读全文和分段朗读均跳过来源ID、参考资料列表与网址。参考资料不代表逐句核验通过。模型认证失败、网络超时、空正文和截断依然显示真实错误。

`CAMPUS_WEB_SEARCH_ENABLED=false` 可停用搜索。搜索采用公开搜索引擎，可能受网络、限流或站点访问限制；这不等于拥有完整馆藏数据库。藏品目录仍应由真实馆方资料维护。

高德 Web 端（JS API）的 Key 写入根 `.env` 的 `CAMPUS_AMAP_JS_KEY`，配套安全密钥写入 `CAMPUS_AMAP_SECURITY_KEY`。安全密钥只在后端代理转发时加入。JS 请求保留 `s=rsv3`、`platform=JS`，不能把 JS Key 当作独立 Web 服务 Key 使用。

有配置时默认载入在线地图。定位须点击开始，提供一次定位、每30秒持续更新、IP城市定位和持续IP城市定位；停止、切校区或离开页面会取消本地等待和后续更新，后台页面暂停轮询。按用户要求，IP区域中心可作为粗略步行起点，界面明确注明并不代表设备实际位置；VPN/代理可能改变结果。地图坐标不进入模型、日志或Git。

地图使用按日期保存的应用发起次数上限：加载100、定位3000、POI搜索100、路线200；仍有限频且不自动规划路线。这是应用计数，不等于高德控制台实际额度。

点位卡片及回答中的“在地图查看”会切换到在线高德地图，以当前校区和地点名称匹配最多5个候选地点。确认名称与地址后可设为目的地；匹配只在内存保留10分钟，不改写本地目录的坐标或核验状态。没有匹配时明确提示，不生成坐标。

步行规划支持设备定位、IP粗略位置、在线地图点击选点或手动坐标作为起点。无起点时可直接点击“从 IP 位置步行到这里”，自动获取IP区域中心；设备/IP位置超过2分钟自动更新，手动选点不因时间推移失效。目的地缺坐标、坐标不精确或资料未核验时自动向高德匹配，不再整段拒绝规划；只有同名匹配存在歧义时才选择候选，选择后自动继续。

点击规划后停止持续定位，固定本次起点，展示高德返回的距离、预计时间和分步指引。可点击“上一步／下一步”、任一步骤或整条路线查看对应图面。高德需要联网，无法定位的IP、服务覆盖以外或超出步行范围的起终点仍可能失败，不编造位置或路线。仅提供步行路线与手动翻步；高德道路结果不代表校门、门禁已核实。

地点匹配和步行请求通过应用的固定同源高德 JS 安全代理发送，前端不再依赖 `AMap.PlaceSearch` / `AMap.Walking` 服务插件回调。地图绘制和设备定位继续使用 JS SDK；无需另配 Web 服务 Key。起终点按6位小数发送，解析高德返回的字符串距离、时间和折线。界面区分目的地匹配、步行规划和地图绘制失败，并显示允许列表内的错误码；不再把这些错误笼统归为权限不足，也不自动跳转外部导航。

语音菜单只保留现有 Xiaoxiao 女声、Yunxi 普通话男声、HiuGaai 粤语和 Jenny 英语。继续使用现有 Edge TTS，不是角色克隆音色。浏览器操作系统音色不再混入菜单。

启动：`scripts/start-app.ps1 -Build`，打开 http://127.0.0.1:8000 。修改 `.env` 后需重启本项目服务。
