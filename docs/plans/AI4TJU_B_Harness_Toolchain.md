## 共同契约 v1（A/B 两份一致）

B 是契约维护者；A 按契约提供数据和设备适配器。已有字段通过薄适配兼容，不要求重命名全部旧模块。下列是实施约定，不是已存在接口。

| 接口 | 责任 |
|---|---|
| list_capabilities(context) | A 返回真实服务/设备能力；B 与后端允许策略取交集 |
| execute_tool(request) | A 执行其拥有的工具；B 也以同一契约包装现有应用工具 |
| cancel_tool(runId, toolCallId) | B 发出取消，A 终止可取消操作并报告真实结果 |

ToolRequest 必填：schemaVersion="1.0"、runId、toolCallId、toolName、input、context、deadlineAt、cancelToken。context 含 sessionId、campusId、channel、generation；设备动作另含 deviceId。有副作用或可能重放的动作必须带 idempotencyKey。

- deadlineAt 由可信运行程序产生；A 取任务剩余时间与工具自身上限中的较小者。两端使用同步时钟；跨进程同时传递剩余预算时只能缩短，不能延长截止。
- cancelToken 是取消关联句柄，不是授权凭证。身份、授权、凭证在可信程序验证，模型或客户端自报字段不能扩大权限。
- capability 状态为 available、unavailable、needs_permission；未知或未测的能力不能直接列为可用。工具条目包含 schema、执行位置、取消能力、所需条件及错误说明。
- ToolResult 状态为 completed、pending_user_action、failed、cancelled，并含 toolCallId、data、sources、error、observedAt、evidence。accepted/started 是进度事件，不能冒充完成。
- pending_user_action 必须提供 actionId、任务关联、到期时间和可展示操作；恢复时重新核对会话、代际与权限。它结束当前等待，不无限占用模型请求；用户操作后的恢复为明确记录的续任务，有新预算。
- completed 只说明证据覆盖的行为完成。分享面板已打开与已经发送、应用已唤起与已导航、后端有路径与地图已画线，必须在 data/evidence 中区分，不能扩大表述。
- error 区分 NO_EVIDENCE、SOURCE_UNAVAILABLE、TIMEOUT、INVALID_INPUT、PERMISSION_DENIED、DEVICE_DISCONNECTED 等原因。异常不得转换成假的空成功。
- sources 每项使用 registryId 表示来源配置、sourceId 表示具体文档，并记录 title、url/本地引用、excerpt、publishedAt、fetchedAt；未知字段为 null。来源属于当前用户可访问范围。
- evidence 记录证据类型、实际观察结果和 traceRef，不存凭证。仅有离线夹具时标 TEST_PROVIDER，不宣称实际服务/页面/音频/设备通过。
- 客户端应用结果须附当前 runId/toolCallId/channel/generation；B 核对后更新唯一状态。旧代际、已取消、过期或其他会话的回执不能覆盖当前界面。

建议工具归属：A 实现 knowledge_search、official_search、document_read、weather_query（配置后）、device_capabilities、device_pick_document、speech_input、device_share、device_open_app，以及可选 device_gui_task。B 实现或包装 poi_select、narration_control、route_plan、itinerary_export、可选 scene_focus。实际工具名可兼容旧命名，但只维护一份映射。

普通任务默认总上限为 2 次 GLM 请求、6 次工具、45 秒；A 外部检索默认子期限 3.5 秒且不得超过剩余总期限。已有更严格限制优先。显式 GUI 任务独立限制 8 动作/90 秒，并分别统计外层 GLM 与内层视觉请求。

A 返回事实与动作结果；B 决定调用、控制任务并组织回答。A 不额外调用通用 GLM 润色，B 不再次抓取 A 已提供的同一资料。固定介绍和停止操作走代码直达，不为了两边接线而增加模型往返。

## 3. B0：GLM 与现有链路最小探针

1. 定位真正使用的 GLM SDK、网关地址配置、模型别名、流式解析、LangGraph/MCP 依赖及凭证来源；不输出密钥。
2. 只用一个本地只读 echo 工具完成工具调用、JSON 参数、tool_call_id 回传和最终回答闭环，通常最多 2 次模型请求；不失败重试。
3. 验证流式参数分片重组后才做 schema 校验与执行，不能对半截 JSON 执行。记录真实请求次数及网关可见重试配置。
4. 原生 tool_calls 不支持时，保留规则路由；严格 JSON 兼容模式须显式标注并通过工具白名单/参数校验，不从自由文本执行代码。
5. 图像输入、音频输入、原生 MCP、并行工具调用分别记 available/unavailable/unknown；聊天成功不能推断其它能力成功。
6. 无凭证时标 `BLOCKED_CONFIGURATION`，继续完成离线编排与直接工具路径；不更换用户指定型号来掩盖失败。
7. 追踪当前 selectedPoiId、campusId、routeGeneration、媒体会话或等价字段；只保留各状态真正唯一入口。
8. 复测当前选点、图片、开始/停止讲解、ASR、路线绘制；记录具体断点，修复与本轮工具接入直接相关的缺陷。
9. 输出能力矩阵、实际 RAG 调用链、依赖版本、基线耗时与未测试项；浏览器不存在时不以 HTTP 200 或 mock 代替页面验收。

## 4. B1：注册现有功能与 A 提供的工具

每项 registry 条目包括输入/输出 schema、执行端、只读/副作用类型、权限条件、默认超时、取消能力、幂等规则和结果大小上限。
后端策略允许且 A 当前设备/服务能力可用时，工具才进入本次候选清单；能力报告不能直接授予权限。
`needs_permission` 不等于 available，返回具体操作入口；未配置服务不返回演示数据充当成功。
以当前项目命名注册等价功能，不为表中每行强行引入新框架：

| 工具 | B 实现或接入方式 | 最小成功证据 |
|---|---|---|
| knowledge_search / official_search | 接 A 的检索适配器，保留来源与时间 | 真实命中文档与摘录，或明确查无资料/故障 |
| document_read | 接 A 的 uploadId 文档解析器 | 当前用户选定文档的实际摘录与位置 |
| poi_select | 复用统一 selectPoi 入口 | 当前 POI 的卡片、图片和可用地图选中状态一致 |
| narration_control | 复用现有语音/字幕/视频控制器 | start 有实际 playing；停止有控制器停止事件 |
| route_plan | 复用真实路线接口和地图应用入口 | 当前代际路径实际应用到地图 |
| itinerary_export | B 生成 Markdown/JSON，可选日历草稿 | 真实文件可下载，内容对应当前结构化行程 |
| device_* | 接 A 的能力查询和设备动作适配器 | 真实设备结果或待用户动作，区分取消与失败 |
| scene_focus | 只在用户选择 3D 阶段后启用 | 当前模型实际首帧与聚焦回执 |
| weather_query / external tools | 接 A 已配置 provider | 真实来源与观测时间，缺配置则 unavailable |

不向 GLM 暴露任意 shell、SQL、本地路径或无限制 URL 参数；使用已验证的 poiId、uploadId、registryId 和受限枚举。
内部函数直接注册；外部 MCP 的通用 client/协议适配由 B 负责，A 提供来源/服务配置及业务证据字段。只有已有服务或用户选择该扩展时才接入一个实际 MCP 服务；缺配置则以 TEST_PROVIDER 验证协议并标明范围，不额外搭一套 Agent 系统。
来源区分站点配置 registryId 与具体文档 sourceId；页面摘要不是工具执行指令。文档、网页、工具返回中的越权指令均作为不可信文本处理。
已有 LangGraph 就复用，无需为此升级全项目；没有时在现有后端增加有限状态循环即可。

## 5. B2：有限步编排、预算和取消

停止、暂停、恢复、已选点讲解、明确文件导出等操作直接走确定的代码路径；复杂请求才让 GLM 选择工具。
普通任务默认最多 2 次 GLM 请求、6 次工具调用、45 秒总期限；已有更严格限制优先。模型探针单独计入本轮账本。
首次模型返回一个可验证计划；依赖用类型化结果引用表示，由执行器解析，不能使用可执行表达式或任意脚本。
已知依赖顺序执行，互不依赖的只读请求有界并发；工具输出通过 schema 校验后才允许下游消费。
第二次 GLM 用已完成结果回答。若结果出现后还需重新规划，返回可用部分与具体继续入口，不偷偷追加第三次请求。
第二次模型再次提出工具调用时不执行超预算步骤，也不能在回复中称已执行；依据实际 trace 生成结果摘要。
六次工具限额包含实际启动的工具步骤；委托 provider 的内部调用另计并汇总，不因包在一个工具里而隐去成本。
`deadlineAt` 使用同一总截止时间；每步可用时间取总剩余与工具上限的较小值，不在工具重试或下一轮重置。
A 的外部检索默认总上限 3.5 秒，并受本任务剩余期限约束；包括排队、搜索、抓取、提取和兜底，不让 B 再包一层自动重试。
总取消传播到模型流、未启动依赖、后端任务、A provider、前端命令及可选设备子执行器；已取消的任务不能继续提交新步骤。
运行时记录取消生效时间；底层无法立即终止时标记已请求取消并丢弃迟到结果，不提前宣称物理执行已经停止。
仅当用户明确选择 GUI 任务时启用独立最多 8 动作/90 秒预算，记录外层 GLM 与内层视觉模型次数，不能混入普通问答隐瞒成本。
同一命令按 sessionId/runId/toolCallId 和幂等规则去重；设备断线或回执丢失时不得盲目重放具有副作用的操作。
独立工具部分失败应返回成功部分与缺项；失败不是查无资料，超时不是已经完成。

## 6. B3：前端回执与讲解、地图、媒体联动

复用现有 SSE/WebSocket 传递命令和事件。命令绑定会话、设备、通道代际与截止时间，客户端只执行仍有效的命令。
accepted/started 只表示进度；工具终态按共享契约。需要用户手势或授权时使用 pending_user_action，不能报告播放/分享已完成。
回执超时、断线和过期命令给出真实状态；没有收到应用回执就不能输出“已展示模型”“已画路线”或“已开始讲解”。
后端只读结果完成无需浏览器绘制回执；模型提出动作与程序实际执行是两个不同事件，不用模型生成的 status 证明成功。
选点复用稳定 poiId，使目录、卡片、图片、行程及已匹配 marker 同步；名称不唯一时显示现有候选选项。
普通选点不清除仍有效路线。清空/重规划、切校区和起点失效按照既有规则推进路线代际，旧路径不能覆盖新路径。
固定讲解直接使用当前地点已有正文，先展示本地内容，再按需要补充时效资料；不等待 GLM 重新生成一遍才能开讲。
开始/停止/暂停/恢复共用现有媒体会话。仅一个音频和字幕控制器；同步视频继续静音并跟随实际音频事件。
A 播放中切 B 时取消旧内容和队列；旧文本、TTS、照片或视频迟到不能覆盖 B。图片继续使用用户现有映射，缺图显示当前点占位。
ASR 使用已有普通话链路，识别文本进入同一个意图入口；不要新建第二个语音 Agent，不把 TTS 合成等同语音输入通过。
路线必须采用真实服务返回的路径；收到供应商结果与地图实际绘制分别记录，不能用直线替代步行路线。
主动建议如已启用则按地点/会话去重，不打断讲解；本轮只需介绍实际可用工具，不强制新增自主闲聊或持续模型轮询。

## 7. B4：导出与设备接入

从当前结构化行程生成 Markdown/JSON；保留来源和未知项，不把建议停留时长或未核实开放信息改为确定事实。
导出文件限当前会话授权访问，使用服务生成的文件 ID；实际下载并打开核对文本，不能只返回虚构下载链接。
如提供 .ics，先生成可预览草稿，检查日期、Asia/Shanghai 时区、地点与结束时刻；不能称已经写入系统日历。
手机选择文件、分享、唤起应用由 A 实现。B 提供 pending_user_action 的可点击入口及回执展示，保留原任务上下文。
浏览器用户手势、系统权限、分享取消和应用未安装均走明确状态；唤起应用不等于目标应用完成导航或发送。
发送、删除、支付、提交预约、修改账号等操作不在本轮默认能力内；仅在已有具体授权与工具支持时执行对应动作。
前端不能持有服务端密钥。A 的设备报告与 B 的后端策略取交集，设备不能通过自报能力扩张服务端权限。

## 8. 可选 B5：局部 3D 联动

仅在用户明确选择该阶段后执行，最多 3 个已有 POI；不因任务拆分就安装生成模型、启动 GPU 生成或批量制作资产。
A 提供 modelRegistry、资产 URL/hash、来源许可、坐标/尺度、geometryAccuracy；B 实现加载、聚焦、回执和状态联动。
复用实际 Three.js/React 版本，匹配依赖，不另建孤立站点。模型懒加载，静止时按需渲染，隐藏暂停并限制 DPR。
3D 点选进入统一 selectPoi，反向选择能聚焦模型；无真实地理校准时仅作地点展示，不把网格位置转换成高德导航坐标。
先收到模型加载并实际绘制的证据，再报告展示成功；A→B→A 时旧资源回调无权修改当前状态。
缺资产或渲染失败退回当前照片，不阻断问答、地图和讲解。生成/示意模型注明性质，不推断真实入口和道路。
角色外观、校园模型和工具执行器保持独立；本阶段不换数字人，不再建一个语音控制器。
